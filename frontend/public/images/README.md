# Zim-Agro Image Pack

Drop generated images into these folders and keep exact file names.

## 1. Hero Images

Path: `public/images/hero/`

- `hero-main.jpg`
- `hero-alt.jpg`

Recommended specs:
- Size: `1920x1080` (16:9)
- Format: JPG
- Compression target: 250 KB to 550 KB each
- Style: premium commercial agriculture photography, clean natural color grade, no heavy filters

What the images should show:
- `hero-main.jpg`: Zimbabwean farm landscape at golden hour with visible crop rows and one or two farmers in the mid-ground.
- `hero-alt.jpg`: Close-up of hands inspecting healthy crop leaves or seedling trays, modern agronomy feel.

## 2. Pest Diagnostic Images

Path: `public/images/pests/`

- `fall-armyworm.jpg`
- `leaf-rust.jpg`
- `tuta-absoluta.jpg`
- `aphid-colony.jpg`

Recommended specs:
- Size: `1200x900` (4:3)
- Format: JPG
- Compression target: 140 KB to 320 KB each
- Framing: macro/close detail with clear symptom visibility

What the images should show:
- `fall-armyworm.jpg`: Maize whorl with shredded leaves and visible caterpillar damage.
- `leaf-rust.jpg`: Leaf surface showing orange-brown rust pustules clearly.
- `tuta-absoluta.jpg`: Tomato leaf mining trails and fruit boring signs.
- `aphid-colony.jpg`: Clustered aphids on tender stems/leaves with visible honeydew effect.
